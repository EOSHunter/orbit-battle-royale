# Main menu v0.2 — sci-fi UI exploration

[View the concept](main-menu-scifi-ui.png).

Generated with the built-in image_gen tool. The user's clarification was to change the UI itself; the background will be replaced independently. This selected concept therefore uses a plain navy canvas.

## Direction

- Extended geometric title typography with an orbital O motif.
- Four indexed navigation modules: Play, Training, Settings, Credits.
- Engineered panel edges, fine structural rules, restrained corner chamfers.
- Pale-lime selected outline/bracket and directional action glyph.
- Existing navy, ivory, and pale-lime palette.
- Quiet right half reserved for the user's future background.

This is an alternate visual concept, not an approved replacement for the menu or the global design system. Earlier menus remain intact. The more angular panel language is an exploration beyond the original restrained rectangular components.

The raster wordmark and typography need deliberate vector/font work before production. Navigation indices are decorative, not new bindings. Enter/Esc hints are illustrative and must follow actual input rules. Generated thin lines, background opacity, contrast, scaled text, responsive layouts, and focus need implementation review. This does not implement a UI or promise a transparent overlay asset.
