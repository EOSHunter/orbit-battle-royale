# Reference inspection notes

Reference: [Kong Royale working prototype](https://eoshunter.github.io/kong-royale-feedback/#play-hud), inspected 2026-10-12.

The full-screen prototype toolbar exposes Screen and Compare selectors. The actual design-system selector appears on the Session page header. We returned to Session, selected **Hybrid** in the Design system dropdown, verified Hybrid as selected in the browser state, then reopened the prototype. Hybrid remained active for subsequent screen inspection.

## Observed screens

The Screen dropdown exposes Lobby, Loading, HUD, Match menu, Mouse & keyboard, Controller, Audio, Video, Accessibility, Report, Learn controls, Inventory, Map, and Results.

Settings subsections inspected: Mouse / Behavior / Bindings; Controller Layout / Look / Deadzones; Audio Volume / Voice; Video Display / Graphics; Accessibility Comfort & readability.

Visible layout: consistent Settings title, horizontal category navigation, local section tabs, continuous rows with aligned controls, selected row surface/marker, right-side authored help/diagram, Restore defaults and saved-state footer. Hybrid supplies stronger selected surfaces and softly rounded controls while retaining the shared shell.

Other layouts: editorial lobby hero with one Play action; loading phase/progress and a contextual tip; left-aligned match menu; dedicated report form; lesson-index guide; map-dominant view with legend/marker actions; outcome-led results with a typographic stat row.

## Orbit adaptations

Keep midnight navy, ivory, pale lime, cyan shields, coral health, Veyra/Ringfall, original operator/equipment, and 60 combatants. Replace reference-specific gorillas, island names, banana weapons, yellow branding, Trios, 50-player counts, and Resurgence.

Extend the Orbit settings concept to controller bindings, accessibility subsections, and Gameplay HUD. Separate asset downloading from preparing the match. Cover both victory and elimination and the two confirmation dialogs.

Generated menu images use the existing Orbit inventory/POV/asset concepts plus a new settings anchor as visual references; the external prototype supplied observed structure and interaction context. Screenshots from the external prototype are not distributed in this package.
