# Orbit Royale concept art v0.2

48 requested concepts generated with the built-in image_gen tool, following the supplied asset list. The gallery selects one image per concept. Two first drafts are retained alongside their refinements, for 50 PNG files total.

## Browse

Open [index.html](index.html) in a browser. Click an image to open its full-size sheet. [manifest.json](manifest.json) identifies every selected image and retained first draft. [source-list.txt](source-list.txt) preserves the supplied brief. [prompts.md](prompts.md) records generation prompts.

## Review

All selected concept images were visually inspected. Field Patch was refined from a hard case into the requested soft folded pouch. The equipment icon sheet was refined to use four ammunition-box icons instead of an unrequested rocket silhouette. Its background uses actual PNG transparency; verify contrast on the intended UI surface before using it.

Kestrel is depicted without mounted weapons. Phoenix remains a full-health/full-shield consumable: the source's revival wording does not establish a revival mechanic. Descent options are alternatives, not an approved choice. Weapon, operator, and vehicle multi-view sheets are modeling references; their geometry is not guaranteed to be mechanically consistent.

Logo and icon sheets are raster explorations, not vector masters or production-ready glyphs. Environment scenes, sky/celestial placement, and the illustrated map require a later consistency pass with the chosen skybox and level layout. Generated details do not automatically establish new game mechanics, points of interest, or final branding.

No game code, 3D models, final vector logos, or engine decision are included in this concept set.
