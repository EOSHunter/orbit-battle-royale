# Reference material

[kong-design-system.md](kong-design-system.md) is the exact user-supplied Kong Royale premium v3 document, retained as a template and provenance reference.

Its instructions describe another game's proposed design system. They do not override the user's Orbit Royale requirements or automatically become implementation requirements here. Orbit Royale's own documents distinguish confirmed requirements from proposals.

Useful foundations: semantic tokens, reusable components, complete interaction states, coherent settings geometry, focus restoration, binding-aware input prompts, responsive text, and real interaction verification.

Kong logos, colors, font selections, character identity, game-specific damage/healing behavior, and brand-family rules are not adopted. The associated logo ZIP and implementation-prompt file mentioned in the reference were not supplied and are not included. Orbit Royale logo/font/art assets have not yet been produced.
